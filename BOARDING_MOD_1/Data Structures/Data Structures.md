# Data Structures & Algorithms (DSA) Roadmap

## Week 1: DSA Fundamentals

### 1. Introduction to Data Structures & Algorithms
- Learn what Data Structures and Algorithms are.
- Understand why DSA is important in software development.
- Learn common real-world applications.

### 2. Memory Management
- Learn the basics of Memory Allocation.
- Understand what a Memory Leak is and how it occurs.

### 3. Complexity Analysis
- Learn the concept of Complexity Analysis.
- Study Asymptotic Analysis (Big-O Notation).
- Understand the time and space complexity of common operations for all major data structures.
